## 打包（`android/tools/build.py`）

无 Gradle：aapt2 → javac → d8 → zipalign → apksigner；R8/D8 用 JDK 17 跑（JDK 21 存在兼容 bug）。
资源先复制到 ASCII 工作目录（默认 `D:\g4build`，因为 aapt2/zipalign 打不开含中文的路径），
最后把 APK 拷回 `android/out/`。

```bash
python android/tools/build.py --version-name 1.1.0 --version-code 2
```

签名口令**不在源码里**，按优先级取：`--store-pass` 参数 → 环境变量 `G4_STORE_PASS` →
`android/.keystore-pass`（该文件不入库）。三者皆缺时构建会直接报错并打印这三种给法。
