# 重力四子棋（HTML 版）

单文件 HTML 重力四子棋：人·人 / 人·机（易/普/难）/ 机·机 / 联机对战。
支持悔棋、复制对局记录、导入残局、危险提示、房规配置。

## 文件说明
- `index.html` — 主游戏（所有规则/物理/AI 内嵌于单文件）
- `四子棋服务器.js` — 联机服务器（Node，`node 四子棋服务器.js [端口]`）
- `start-online.js` — 一键开房：起服务器→自动打开浏览器房间
- `一键开房.bat` — 双击运行 start-online.js（需本机已装 Node）
- `_ai_stats.js` — 困难 vs 困难批量对局统计 runner（`node _ai_stats.js [局数]`）
- `_drive.js` + `drive_state.json` — 命令行"我下棋、AI 应手"交互驱动器
- `g4_ai_stats.csv` / `g4_ai_stats_rand150.csv` — 历史统计样本

## 本地运行
在 `server/` 下双击 `一键开房.bat`（需 Node），或直接双击 `index.html` 单机游玩。

## AI 说明
启发式评估（非神经网络）：静态窗口分 + 一步杀/双威胁计数 + 多层威胁前瞻（普通/困难按强度分档）。
权重可用 `tools/tune-weights.js` 进化调优，多局并行用 worker_threads。
