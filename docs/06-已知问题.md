# 已知问题

## 1.（已修复）工具链无法读取双 script 的游戏页面

`index.html` 含 **两个** `<script>` 块：游戏逻辑 + 注入的 NN 权重（`__NNW`）。
旧的 script 提取正则用了贪婪匹配 `/<script>([\s\S]*)<\/script>/`，会把第一个块的
`</script>` 一起吞进 JS，直接 `SyntaxError: Unexpected token '<'`。

影响文件（已改为与 `tools/neural/env.js` 一致的非贪婪写法）：

```
tools/ab-ai-check.js:5
tools/ai-stats.js:7
tools/drive.js:8
tools/selfplay-core.js:29
tools/tune-weights.js:81
```

复现（修复前）：`node tools/drive.js NEW red` → `SyntaxError: Unexpected token '<'`

## 2.（待修复）旧工具链未适配 async 版 `aiChooseMove`

`index.html` 里 `aiChooseMove` 已改造为 **async 函数**（内部用 `yieldFrame` 让出帧），
但 9/4 那一批旧工具仍按同步调用，拿到的是 Promise 而不是落点坐标：

```
tools/selfplay-core.js:46     const d = G.aiChooseMove();     // 缺 await
tools/tune-weights.js:105     const d = cur.aiChooseMove();   // 缺 await
tools/ab-ai-check.js:26,56    const c = G.aiChooseMove();     // 缺 await
tools/ai-stats.js:54          const c = G.aiChooseMove();     // 缺 await
tools/drive.js:103,126        const c = G.aiChooseMove();     // 缺 await
```

**症状**：自博弈「一局」只走 1 步就以红胜结束；驱动器让 AI 应手时棋盘不落子。

复现：

```bash
node -e "const {playSelf}=require('./tools/selfplay-core.js');console.log(playSelf('hard'))"
# 实测输出：{"n":1,"winner":1,"ms":9,"slow":8}      ← n 应为 20+
```

```bash
node tools/drive.js NEW blue     # 期望 AI（红）先落一子，实测棋盘仍为空
```

**修复要点**（不能只加 `await`）：`aiChooseMove` 内部依赖 `requestAnimationFrame`，
沙箱桩 `rAF:()=>0` 永不回调会导致 `await` 直接挂死。需照搬 `tools/neural/env.js` 的做法 ——
加载期用 noop 吞掉 rAF（防止动画 loop 无限递归），加载完成后替换为同步触发：

```js
sb.requestAnimationFrame = (cb) => { cb(); return 0; };
```

未受影响的管线：`tools/neural/`（`env.js` + `agents-*.js` 均正确 `await`），
NN 训练与评测走的是这条线。

## 3. Android 签名口令硬编码

`android/tools/build.py:35` 有 `STORE_PASS = "g4g4g4"`，与 `android/g4.keystore` 配对。
keystore 已加入 `.gitignore` 不入库；但若口令与 keystore 同时泄露，他人可签发被系统
认可为「同应用更新」的 APK。建议改为从环境变量读取（如 `os.environ["G4_STORE_PASS"]`）。
