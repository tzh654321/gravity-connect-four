重力四子棋 · 规则

一、棋盘与坐标

  • 棋盘是无限大的方格阵，格心坐标为整数 (x, y)，y 轴向上为正。
  • 中央 (0, 0) 有一个固定块，不属于任何一方，并且会阻断连四。

二、重力场（四个分区）

  • 右上（x ≥ 0，y ≥ 1，含 +y 轴）重力向下；右下（x ≥ 1，y ≤ 0，含 +x 轴）重力向左；
  • 左下（x ≤ 0，y ≤ −1，含 −y 轴）重力向上；左上（x ≤ −1，y ≥ 0，含 −x 轴）重力向右。
  • 四个分区首尾相接，形成一个向中心汇聚的螺旋重力场：棋子会先落到坐标轴上，再沿轴滑向中央，围绕固定块堆成十字形。

三、落子与结算

  • 轮到自己的回合时，左键双击任意空格，棋子出现在该格正中间。
  • 落子后先检查重力方向的相邻格：有棋子或固定块 → 立即固定；为空 → 进入带空气阻力的自由下落（连续坐标，不吸附网格）。
  • 下落中撞到其它棋子或固定块 → 对齐一次网格，然后重新检查重力方向，如此循环，直到固定。
  • 必须等棋子完全固定后，才会轮到下一回合。

四、胜负

  • 任意方向（横 / 竖 / 两条斜线）连成 4 子即获胜，固定块阻断连线。

五、操作

  • 滚轮 平滑缩放　左键拖拽 平移视野　双击 落子
  • 空格 回到原点　N 重新开局
