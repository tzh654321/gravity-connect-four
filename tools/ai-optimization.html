二、为什么"再调参 / 扩网"没用：三大天花板

天花板 A评测基准是"自己打自己"——循环基准

被测的 html-leader = aiChooseMove + quietNega 迭代深搜 + 16 维 MLP 叶子；对手 内置 hard = aiChooseMove + 启发式叶子。二者同一套搜索骨架，只差叶子。所以它们天然对等。而 eval.js 只测"对 hard 胜率"，于是所有变体都绕 54% 打转——这不是"强度都够好"，是基准无法区分强弱。

证据：eval_result 探索矩阵中 blue_q16、branch8、blueDeeper、red_idA 等 11 组全落在 27.5%~65% 且无一组稳定超噪声；final_p1.json（html agent, d4 b6）40 局 25胜15负 ≈ 54.2%。

天花板 B数据是"教师锁定"的——网络永远追不上老师

collect.js 用内置 hard 自对弈产局，train.js 用终局 ±1 作标签。由于 hard 与 NN 处于同一平台，标签和训练分布都被 hard 封顶：NN 只是在模仿 hard，不可能超越 hard。这正是反弹棋 NN 失败（弱教师锁死 + 镜像对称）的同一类根因。

证据：collect.js L14-46 数据采集来源 = builtinAgent(diff)；train.js L6 标签即 t:-1|0|1 单局二元。

天花板 C安静局面搜索太浅 + 特征缺乏不变性
维度现状上限

三、优化路线图（按杠杆/成本排序）

P0 · 先修"尺子"（成本最低、杠杆最高）

动作做法解决
建 Elo 天梯把 内置hard / 当前NN / 候选 都注册为玩家，跑固定交叉对局算 Elo±CI天花板 A：让"真变强"显形为 Elo 上升而非 54% 噪声
弱对手池增加 内置normal/easy 作固定陪练，"胜率"不再被先手平局封顶天花板 A：强度可独立于先后手度量
测批确定性排名阶段关掉 diversifyPick 随机/加 bootstrap CI小增益不再被噪声淹没

P1 · 打破教师锁：自博弈 RL / MCTS（真正的跃升）

动作做法预期
自博弈数据让 NN 自己打自己（或 NN vs NN + 偶发 hard），以终局标自身数据再训练，迭代脱离 hard 天花板（AlphaGo/Zero 路径）
上 MCTSNN 同时做 策略+价值 头，每手 200~2000 次模拟；比定深 alpha-beta+价值网 通常更强同等 1.2s/手 预算下有效搜索更深
TD(λ) 目标用自举价值替代单局二元标签，降方差训练更稳、泛化更好
这是反弹棋分析后给过的同一结论：函数逼近器 + 搜索 + 自博弈 才是上限形态。当前项目设施（MLP、自博弈、注入）已齐，缺的是"数据来自自身而非固定教师"。

P2 · 强化价值网输入（便宜，与 P1 复利）

改进说明
对称增广训练时 8 向变换增广，使网学会旋转/镜像不变性（直接修复反弹棋 NN 的镜像失效）
特征扩维加 距中心直方图、机动性(可达落点数)、对手潜伏线计数、>my3 的形状直方图；16 维过压缩
策略头预测每步优劣，供 MCTS 选择 + 剪枝

P3 · 搜索效率（抬高单位时间可达的上限）

改进说明
转置表把 trans/ 雏形接进 threatNega/quietNega，复用强制线子树
迭代加深 + 渴望窗口 + killer 着现有 ID 框架上补，减少无效展开
若走 MCTS策略头剪枝即"更深的有效搜索"，1.2s 预算内收益最大

P4 · 游戏层杠杆（可选，针对 55–63% 先手墙）

当前"胜率天花板"部分是游戏本身的先手优势，不是 AI 弱。连珠/六子棋类标准做法——交换规则（swap：后手可交换先后手）——能中和先手偏置，让"强度"独立于颜色可度量；届时真正更强的 AI 即便在 swap 下也能压制。属房规层面改动，可单独评估。

四、不要再做的（纯浪费）

  • 继续调启发式权重（tune-weights.js）—— 工具 README 已明说"默认权重已是局部较优点，纯调数字收益有限"。
  • 继续网格搜 leader 搜索参数（qN/branch/depth/叶子族/richMix）—— eval_result 探索矩阵证明全部同平台、无稳定增益。
  • 只扩 MLP 而不改数据与特征—— 在教师锁 + 浅特征下，加大网络只是更贵地拟合同一平台。

五、一句话总结

引擎早已"够强到与自身对等"，但被循环基准 + 教师锁 + 浅搜索三道天花板压在同一个先手平台上。下一步的杠杆不是"再调"，而是 P0 换把尺子（Elo 天梯）→ P1 用自博弈/MCTS 让网络脱离固定教师自举；特征增广与转置表是便宜的复利项。把这两步做出来，AI 才有机会真正超越当前 54% 的"平局线"。
